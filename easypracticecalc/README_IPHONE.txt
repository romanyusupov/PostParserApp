КАЛЬКУЛЯТОР ПРАКТИК — ОФЛАЙН PWA ДЛЯ IPHONE

Что внутри:
- index.html — калькулятор;
- manifest.webmanifest — параметры веб-приложения;
- sw.js — офлайн-кэш;
- icon-180.png, icon-192.png, icon-512.png — иконки.

КАК УСТАНОВИТЬ НА IPHONE

1. Загрузите ВСЕ файлы из этой папки в одну папку на сайте с HTTPS.
   Например:
   https://ваш-домен.ru/calculator/

2. В Safari на iPhone при наличии интернета откройте:
   https://ваш-домен.ru/calculator/

3. Дождитесь полной загрузки страницы.

4. Нажмите:
   Поделиться → На экран «Домой».

5. Если iPhone показывает переключатель «Открывать как веб-приложение» —
   включите его и нажмите «Добавить».

6. Запустите калькулятор с новой иконки ОДИН РАЗ при наличии интернета.
   После этого можно включить авиарежим: калькулятор продолжит работать.

ВАЖНО
- Все вычисления и данные находятся внутри приложения.
- Внешние шрифты, CDN и другие интернет-зависимости удалены.
- Для работы после установки интернет не нужен.
- При будущих обновлениях файла sw.js нужно менять имя CACHE_NAME
  (например v1 → v2), чтобы iPhone гарантированно получил новую версию.
