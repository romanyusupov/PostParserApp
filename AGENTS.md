# Правила работы с репозиторием

- Отвечать пользователю на русском языке.
- Перед внесением изменений изучать связанные файлы и учитывать существующую архитектуру.
- Не помещать в Git секреты, токены, пароли, session-файлы и реальные файлы `.env`.
- Для Instagram запрашивать только разрешение `instagram_business_basic`.
- Не добавлять разрешения на публикацию, удаление, комментарии и сообщения.
- Не изменять рабочий VPS без отдельного подтверждения пользователя.
- Перед созданием коммита показывать пользователю diff.
- Проверять Python-код с помощью `py_compile`.
- Проверять JavaScript-код с помощью `node --check`.
- Делать небольшие изолированные изменения.
- Не создавать коммиты и не выполнять push без прямого указания пользователя.
