# Правила работы с репозиторием

- Отвечать пользователю на русском языке.
- Перед внесением изменений изучать связанные файлы и учитывать существующую архитектуру.
- Не помещать в Git секреты, токены, пароли, session-файлы и реальные файлы `.env`.
- Для Instagram OAuth разрешён только следующий исчерпывающий список scopes:
  - `instagram_business_basic` — только для чтения базовых данных профессионального Instagram-аккаунта и публикаций;
  - `instagram_business_manage_insights` — только для чтения Insights.
- Не добавлять другие Instagram OAuth scopes без отдельного решения пользователя, включая разрешения на публикацию, редактирование и удаление материалов, управление комментариями, сообщения, управление аккаунтом и рекламу.
- Приложение не публикует, не редактирует и не удаляет материалы, не работает с сообщениями и комментариями.
- Не изменять рабочий VPS без отдельного подтверждения пользователя.
- Перед созданием коммита показывать пользователю diff.
- Проверять Python-код с помощью `py_compile`.
- Проверять JavaScript-код с помощью `node --check`.
- Делать небольшие изолированные изменения.
- Не создавать коммиты и не выполнять push без прямого указания пользователя.
